# Перший preview на npm (0.1.0) — план імплементації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Статус: чернетка, чекає рев'ю власника. Архітектор задачі — сесія, що
написала план; якщо її немає — власник.

**Мета:** `simetra` і `@simetrajs/designer` версії `0.1.0` зібрані, перевірені
по розпакованих tarball-ах і опубліковані на npmjs: перша версія — руками
власника з 2FA, далі — CI на merge у `main` через npm Trusted Publishing (OIDC).

**Архітектура:** розробка лишається на сирому TS (dev-`exports`); пакет іде з
`dist`, зібраного tsdown, через `publishConfig`. Кожен ярус `simetra` — окремий
entry, а самопосилання `simetra/<ярус>` лишаються зовнішніми, тож ярус у `dist`
існує в одному екземплярі. Гейт пакування (окремий vitest-проєкт `packaging` у
`@simetrajs/designer`) пакує обидва пакети, ставить їх у тимчасовий проєкт
споживача через `npm install` і проганяє імпорт, CLI і MCP. Публікацію робить
скрипт `scripts/release/publish.mts`: `pnpm pack` + `npm publish` (OIDC
обмінює npm CLI; підтримку OIDC у `pnpm publish` не підтверджено).

**Стек:** pnpm 11 workspace, tsdown (0.x, точний pin), publint, `@arethetypeswrong/cli`,
Vitest, GitHub Actions, npm CLI ≥ 11.5.1.

**Спека:** [платформна спека](../specs/2026-09-24-simetra-platform-design.md)
§11 «Доставка», §12 (порядок, пункти 2 і 6), рішення Р1 (lockstep), Р19 (точний
pin); [спека designer](../specs/2026-10-02-simetra-designer-design.md) §5.3.
Еталон реалізації — сусіднє репо simplyCMS: `.github/workflows/publish-packages.yml`,
`scripts/build-packages.mjs`, `packages/simplycms/tsdown.config.ts`,
`docs/architecture/release-process.md` (читати, не копіювати сліпо).

## Global Constraints

- Версія всіх публікованих пакетів одна (Р1); корінь `simetra-monorepo` лишається `private`.
- Залежності 0.x — точна версія без діапазону (Р19, `CONTRIBUTING.md` § "Dependencies"); ліцензію перевіряти у файлі `LICENSE` репо джерела.
- Публікується лише `simetra` і `@simetrajs/designer`; імена `create-simetra` та інші не займаються.
- Публічна поверхня `simetra` у пакеті — лише `./model`, `./compiler`, `./schema`, `./schemas/*`; заглушки ярусів `./server`, `./data`, `./ui`, `./shell` у `publishConfig.exports` не потрапляють (dev-`exports` лишаються як є).
- `repository.url` кожного маніфесту — рівно `git+https://github.com/VSydorenko/Simetra.git` з `directory`: provenance Trusted Publishing звіряє його з репо воркфлоу.
- `homepage` — GitHub-репо, не `simetrajs.dev` (сайту ще немає).
- README пакетів — англійською, без імен споживачів і без маркетингових слоганів (позиціонування ще не ухвалене); статус — чесний pre-alpha preview.
- Скрипт `build` пакетів (його кличе `turbo build` і `^build` у `turbo test`) не змінюється; збірка пакета — новий скрипт `build:package`.
- Без `--` перед шаблоном vitest; коміти — Conventional Commits українською, без трейлерів.
- Правка `AGENTS.md` (Задача 4) — у межах цього плану, апрув власника на рев'ю плану є дозволом.
