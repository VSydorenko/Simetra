# П4-B3-1 — каркас T4 і рантайм даних: план реалізації

> **Статус:** виконано (2026-11-07, гілка `feat/p4-b3-1`); PR відкриває
> архітекторка. Підсумок аудиту — наприкінці файла.
>
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** пакет `simetra` отримує ярус T4 `simetra/data` як публічний вхід:
закріплені RC TanStack DB у peer-залежностях, лінт-зону й гарди, що тримають
бібліотеку за модулем фасаду, гейт однієї копії бібліотек у споживача, рантайм
даних сесії з власним `QueryClient` і адаптер Server Function поверх
`DataTransport`.

**Architecture:** T4 (`packages/simetra/src/data`) імпортує лише `simetra/model`,
`zod`, `react`, `@tanstack/db`, `@tanstack/react-db`; `@tanstack/query-db-collection`
і `@tanstack/query-core` — лише модуль фасаду `src/data/facade/`. Рантайм даних
живе у фасаді; публічний вхід `simetra/data` не експортує типів `@tanstack/*`.
Адаптер Server Function — тонка обгортка `DataTransport` (Рд4, §5.2).

**Tech Stack:** TypeScript 7, Zod 4, `@tanstack/db` 1.0.0-rc.1.4,
`@tanstack/react-db` 1.0.0-rc.1.4, `@tanstack/query-db-collection` 1.5.1,
`@tanstack/query-core` 5.107.1 (свіжі на 2026-11-07; ті самі версії перевірив
[спайк B3](../specs/2026-11-07-p4-b3-facade-spike-report.md)), React 19.3,
tsdown, ESLint 10 + typescript-eslint з типами, syncpack 15, Vite 8.3 (лише
скретч-споживач гейта).

**Spec:** [спека П4-B](../specs/2026-11-05-p4-b-client-data-design.md) — Рд4,
Рд5, Рд13, Рд15, §3 («Блок чистоти T4», «Модуль фасаду», «Лінт із типами для
T4», «Публікація й залежності», «Гейт `pnpm deps:check`», «Гейт єдиності»),
§5.1–§5.2, §6.1 («Рантайм даних», «Ізоляція кешу»), §11 інв. 1 і 12, §12
(рядки «лінт, AST-гард, типи», «пакування», unit T4 — `dispose()`, ізоляція,
`session-changed`), §13 (рядок B3-1), §14.3 (рядки B3). Звіт спайку B3.

1. **Друга копія T0 у `dist/data`** через відносний імпорт `./../model` чи
   спільний чанк tsdown — пак-тест «each tier is self-contained» і негативні

   відповідь, що прийшла після `dispose()`, нікуди не пишеться (задача 5).
4. **Дві копії `@tanstack/db`/`query-core`** у бандлі споживача з власним
   `@tanstack/react-query` — гейт єдиності (задача 6) на ізольованій
   розкладці pnpm; гейт вимагає присутності кожного пакета (0 — провал).
5. **`.d.ts` тягне `@tanstack/*`** через тип повернення рантайму — пак-тест (задача 6).
