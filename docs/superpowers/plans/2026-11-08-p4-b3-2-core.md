**Interfaces:**

- Produces:
  ```ts
  interface Scope { assert(): void }           // кидає поза commit
  interface GenerationToken { readonly valid: boolean }
  type CloseReason = "disposed" | "session-changed" | "signed-out" | "subject-changed"
  interface Session {
    readonly subject: string
    readonly signal: AbortSignal
    readonly closed: CloseReason | undefined
    readonly epochs: Epochs
    token(): GenerationToken                   // сесійний
    childToken(isValid: () => boolean): GenerationToken // підмножина, спроба
    commit(fn: (scope: Scope) => void, token: GenerationToken): boolean
    onFlush(listener: () => void): () => void  // одна пачка на commit
    close(reason: CloseReason, purgeAll: (scope: Scope) => void): void
  }
  function createSession(options: { subject: string; limits: CoreLimits; log: (e: CoreLogEntry) => void }): Session
  ```
  `close`: якщо `reason ≠ "disposed"` чи є дані — спершу `commit(purgeAll)`
  (одна пачка сповіщень), потім `abort`, недійсність токенів, `epochs.clear()`,
  зняття слухачів. Вкладений `commit` кидає. Слухач, що закрив сесію, не
  зупиняє інших: перевірка `closed` перед кожним викликом; збій слухача —
  `log({ kind: "listener-failed", error })`. Запис з недійсним токеном —
  `log({ kind: "late-response", what })`.
