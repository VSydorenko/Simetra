## Мета, архітектура, спека

**Мета.** Сигнал змін оновлює рядки ядра одним пакетом за кроками §8.4;
приєднання без `recovered` перечитує пропущене одним пакетом після
джитера; відмова каналу прибирає дані пари. Готово (рядок B5 §13, частина
приймача): unit приймача на фейковому каналі з `recovered` і модельний
тест з кроками сигналу зелені; бюджети §12 для сигналів — тест-інваріанти.

**Архітектура.** Приймач — модуль ядра (`store/receiver.ts`), який створює
`createCore`, коли рантайм має фабрику транспорту й каталог має
`rightsSnapshot` (1-Р6). Він бачить внутрішнє ядра: збирач пакета
(`readKeys`, `known`), `Writer` через `commit` з токеном, планувальник B5c,
`session.sleep`, обмежувач читань, знімок сесії й подію його заміни. Тож
нового публічного API ядра (`readKeys`, `markViews` назовні) немає. Таймерів
у приймача немає поза сесією: пачка й дочитування — `session.sleep`, строк хвилі
приєднання — доданок `schedulerDue` ядра (Р10).

**Спека.** П4-B: §6.1 (позначки, `commit`), §6.2 (правило версії, епоха,
`stale`), §6.3 (single-flight, обмежувач), §6.4 (`hasNewRows`), §6.5,
§8.1 (сумісність уперед), §8.3, §8.4 (повністю), §8.5, §8.6, §11
(інваріант 16), §12 (рядок «unit T4 (приймач…)», бюджети сигналів,
мутації приймача).

## Глобальні обмеження

- Запис — лише `commit(fn, token)`; після `dispose()`, `session-changed`,
  `purge` пари — 0 записів і 0 запитів від сигналу, відповіді чи таймера.
- Кожна подія — один синхронний прохід; частини одного ходу йдуть у збирач
  однією мікрозадачею (B3-8); перечитування несуть `known`.
- Сталі (одне місце, `store/receiver.ts`): тиша пачки `QUIET_MS = 50`,
  найдовша пачка `MAX_BATCH_MS = 2000`, дочитування мінімальної версії
  `MIN_VERSION_RETRIES = 3` з паузою `500 × 2^(n−1)` мс, джитер приєднання
  `REJOIN_JITTER_MS = 2000`, тиша зняття «розриву» після `recovered: true`
  `RECOVERED_SETTLE_MS = 50`, вікно дедуплікації `SEEN_SIGNALS_MAX = 4096`
  останніх `id`; межа ключів — `limits.keysPerRequest` (200), власної сталої
  немає.
- Без shims: стара форма порту (`SignalErrorKind`, `onSubscribed` без
  аргументів) зникає в задачі 1.
- Послаблення будь-якого оракула, бюджету чи допуску моделі — розвилка до
  архітекторки.
