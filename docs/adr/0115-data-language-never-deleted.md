# ADR-0115: мову даних не видаляють — її вимикають

Status: accepted 2026-11-25
Decided by: owner
Spec: [мультимовні дані](../superpowers/specs/2026-11-24-multilingual-data-design.md) §5.2

## Context

Мова даних — рядок довідника «Мови» (ADR-0113). Таблиці перекладів щільні: для кожної мови є рядок на кожен рядок мультимовного об'єкта в усіх тенантах (ADR-0112). Видалення мови означало б масове стирання рядків перекладів через межу тенантів одним записом глобального довідника; аудит специфікації знаходив у цьому шляху й дефекти безпеки (друге міжтенантне стирання), й дефекти доступності (необмежена транзакція).

## Decision

Мову даних не видаляють ні фізично, ні позначкою видалення: роль `languages` не має `<t>_delete`, тригер відмовляє обом. Мову, що більше не потрібна, вимикають (`disabled`); помилково додану — так само.

## Why

- Єдиний санкціонований запис платформи через межу тенантів лишається один — заповнення мови.
- Рядки мови `disabled` нікому не шкодять: гість і читачі без права редагування їх не бачать, а повторне ввімкнення повертає переклади.

## Rejected

- Видалення мови, на яку ніщо не посилається (рішення першого e-commerce застосунку-кандидата) — у щільній моделі рядки перекладів посилаються на кожну мову, тож «ніщо не посилається» тут не буває.
- Видалення неопублікованої мови без перекладів з порційним прибиранням копій — ще один міжтенантний запис і окрема машина станів заради рідкісної дії.

## Consequences

- Набір рядків «Мов» лише росте; вимкнені мови лишаються в довіднику.
- Обсяг таблиць перекладів враховує й вимкнені мови.
