# ADR-0018: Прототип заморожено в `legacy/` як референс; метамодель T0 перебудовується на місці

Status: accepted 2026-09-28
Decided by: owner
Spec: [спека П2](../superpowers/specs/2026-09-28-p2-metamodel-compiler-design.md) §2 (М8, М9), §11; [платформна спека](../superpowers/specs/2026-09-24-simetra-platform-design.md) §14

## Context

Прототип складався з конфігуратора, прототипного CLI, генераторів і UI-пакета
над метамоделлю, яку П2 переписує. Підтримувати UI й CLI над метамоделлю, що
змінюється, — марна праця. Водночас їхня логіка корисна як референс для нових
реалізацій.

## Decision

- Прототипні `apps/web`, CLI, `generator-pg`, `generator-api` і прототипний пакет UI
  заморожено поза workspace до П6: у git лишаються як референс для читання, не
  збираються й не тестуються (М8).
- Мінімальний П1 — крок 1 П2, одразу після середовища; далі метамодель
  перебудовується на місці в ярусі T0 із зеленими тестами (М9). Компілятор — у T1.
- Код із `legacy/` береться лише як референс для нової реалізації; прототипна
  поведінка — не контракт, поки спека її не прийняла.

## Why

- Не підтримувати UI й CLI над метамоделлю, що переписується (М8).
- Метамодель переписується одразу в ярусі T0, а не переноситься двічі (М9).
- Доля частин прототипу задана таблицею §14 платформної спеки: стане T0,
  лишиться референсом або буде видалено.

## Rejected

- П1 після П2 — метамодель довелося б переносити в нову структуру вдруге.
- Підтримка прототипного UI й CLI над новою метамоделлю — марна праця над тим,
  що перепишеться.

## Consequences

Легше: зелені гейти без зайвого коду, чіткий рівень референсу. Важче: частина
логіки (каскад перейменування, редактори) тимчасово лише читається. Не
«виправляти»: не розширювати пакет, призначений до видалення, і не збирати,
тестувати чи імпортувати `legacy/`; торкатися лише щоб гейти лишалися зеленими.
