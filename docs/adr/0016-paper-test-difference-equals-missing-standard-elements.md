# ADR-0016: Критерій паперового тесту — різниця «скомпільоване ↔ прийняте» дорівнює рівно відсутнім стандартним елементам виду

Status: superseded by ADR-0040
Decided by: owner
Spec: [спека П2](../superpowers/specs/2026-09-28-p2-metamodel-compiler-design.md) §2 (М1, М4), §10.2

## Context

П2 мусить довести, що метамодель покриває прийняті таблиці, а види 1С можна
перевірити на прикладі. Без вимірюваного критерію «повнота» лишається
твердженням. Прийом цілком (П3) неможливий без повноти опису.

## Decision

Мета П2 — повнота фізичного опису кожної таблиці першого споживача; види 1С
доводяться паперовим тестом на одному документі (М1). Тест пройдено, якщо
різниця «скомпільоване ↔ прийняте» в класах об'єктів, які рендерить П2
(таблиці, колонки, обмеження, індекси, енам-типи, коментарі), — рівно відсутні
стандартні елементи виду за його налаштуваннями (М4):

- додавання: стандартні реквізити, ключі й індекси виду, похідні таблиці
  регістрів;
- заміна простого FK чи індексу посилання в межах скоупу на складений із
  носієм скоупу першим на тих самих колонках;
- заміна простого неунікального індексу на той самий з ключем рядка останнім;
- інших видалень і змін немає.

П2 доводить структурну частину; рівність рухів і підсумків на даних —
приймальний тест П3.

## Why

- Різниця стає вимірюваною (М4): повнота перестає бути твердженням.
- Семантика потребує згенерованих оболонки проведення й тригерів підсумків,
  тому поведінку П2 не доводить, а лише структуру
  ([спека П2](../superpowers/specs/2026-09-28-p2-metamodel-compiler-design.md) §10.2).

## Rejected

- Критерій «повнота» без вимірюваної різниці — лишається твердженням.
- Перевірка поведінки тригерів і рухів у П2 — потребує згенерованої оболонки,
  яка з'являється лише в П3.

## Consequences

Критерій придатний для синтетичного домену, але для реальних об'єктів він
недосяжний без мапінгу й не ловить головного ризику — мовчазної втрати даних.
Тому для промоції реального об'єкта його замінено критерієм ADR-0040. Не
«виправляти» тут: цей запис фіксує, що вирішено 2026-09-28.
