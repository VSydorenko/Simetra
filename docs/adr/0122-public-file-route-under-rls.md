# ADR-0122: публічний файл — маршрут застосунку, що читає рядок файлу роллю гостя під RLS; посилань на байти немає

Status: accepted 2026-11-25
Decided by: architect
Amends: ADR-0060 (публічне читання файлу)
Spec: [публічна частина застосунку](../superpowers/specs/2026-11-25-public-app-part-design.md) §5.6

## Context

Файл — рядок довідника з властивістю `storage`; байти — за портом `FileStore` (`packages/simetra/src/server/file-store.ts`); ключ `o/<об'єкт>/<id>` виводиться з id (ADR-0060). Доступ до байтів — лише через серверний endpoint після читання рядка під RLS; публічних і підписаних посилань немає (ADR-0060, профіль `postgres` §8.2). Заміна файлу — новий рядок з новим id, тож байти за id незмінні. Публічній сторінці потрібні зображення, що віддаються з CDN за сталим URL і зникають, коли рядок знято з публікації.

## Decision

1. Публічний файл — маршрут застосунку `/<префікс>/<id>`: він читає рядок файлового довідника роллю гостя під RLS (`publicRead` з умовою, ADR-0118), далі віддає потік із `FileStore`.
2. Відповідь — за правилом кешу гостя (ADR-0120) з тегом рядка. Невидимий рядок — 404, однаковий для «немає» й «не можна».
3. Inline — лише безпечні растрові типи (`image/png`, `image/jpeg`, `image/webp`, `image/gif`, `image/avif`); решта — `attachment` з `application/octet-stream`. Завжди `X-Content-Type-Options: nosniff` і `Content-Security-Policy: sandbox; default-src 'none'`; `decorate` зливає CSP маршруту, а не затирає.
4. Публічних і підписаних посилань на байти немає; змінюється лише спосіб публічного читання ADR-0060, решта рішення діє.

## Why

- Межу тримає та сама RLS рядка, що й для приватного файлу; відкликання — та сама умова публікації.
- URL сталий: id рядка не змінюється, а байти за id незмінні.
- Файл віддається з origin застосунку: SVG чи HTML inline дали б збережений XSS.
- Тег рядка прибирає файл із CDN тим самим purge, що й сторінку.

## Rejected

- Публічний бакет чи ключ з хешем — виводить доступ за межу RLS; байти живуть до прибирання, CDN без purge.
- Довгі підписані URL — відхилені ADR-0060; «сталий» URL суперечить строку підпису.

## Consequences

- Кожен промах CDN — читання рядка й потік через host.
- Байти знятого з публікації файлу лишаються в сховищі, доки живе рядок; origin їх не віддає.
