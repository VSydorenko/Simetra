# ADR-0069: MCP над даними — лише для бази розробника (loopback і environment = development)

Status: accepted 2026-10-27
Decided by: owner
Spec: [спека П4](../superpowers/specs/2026-10-26-p4-runtime-design.md) §5 (Рт14), §6.15

## Context

Агент MCP діє від імені користувача без власного входу й може змінювати дані. Жодна окрема ознака не відрізняє продакшн: тунель дає loopback, а сесія може сама поставити налаштування бази.

## Decision

- MCP над даними в П4-A — лише база розробника: нова вісь каталогу інструментів `data` (Рт14).
- Запобіжники від випадкового запуску — хост loopback чи unix-сокет і налаштування бази `simetra.environment = 'development'`, яке ставить оператор. Це не межа безпеки: межа — облікові дані `simetra_runtime`.
- Користувач — прапорець запуску; запис у довідники прав — лише з окремим прапорцем запуску.
- Об'єкт із модулем — відмова, доки designer не завантажує модулів.

## Why

- Жодна з двох ознак окремо не відрізняє продакшн, разом вони ловлять випадковий запуск (Рт14).
- `confirm` дає сам агент, тож для прав рішення людини — прапорець запуску (Рт14).
- Без хуків агент обійшов би валідацію застосунку (Рт14).

## Rejected

- MCP над даними на продакшн — немає надійної ознаки середовища (Рт14).
- Підтвердження `confirm` як захист запису прав — його дає сам агент (Рт14).

## Consequences

Запобіжники слід розглядати як захист від випадку, а не від зловмисника (спека П4 §6.15). Розширення на продакшн потребує нового рішення. Вісь `data` відокремлена від осей доступу інструментів у ADR-0032.
