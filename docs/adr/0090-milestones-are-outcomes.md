# ADR-0090: віха — результат із критерієм «що показати»; частина системи — мітка; спека й блок — issues; статус лише в GitHub

Status: accepted 2026-11-15
Decided by: owner
Spec: [ROADMAP](../ROADMAP.md)

## Context

Дорожня карта змішувала три різні речі: результат («що можна показати»),
частину системи і пакет коду. Через це статус не читався, а «Віха 1»
закінчувалась кроком, який не розпочато, поки подальша робота йшла далі.
Окремо статус дублювався в документах і розходився з роботою.

## Decision

- Віха — це результат із критерієм «що можна показати»; вона закривається,
  коли критерій виконано.
- Частина системи — мітка GitHub; вона ніколи не закривається.
- Спека і її блоки — issues: блоки — підзадачі (sub-issues); віха блоку береться
  зі стовпця «Віха» таблиці блоків спеки.
- Статус живе лише в GitHub; документи містять лише зміст.
- Віхи: М1 Фундамент (закрита при створенні), М2 Перша міграція споживача,
  М3 Перший екран, М4 Realtime і права на клієнті, М5 Повні екрани довідника
  (разом з візуальною мовою), М6 Документ із проведенням (паралельно з М5),
  М7 Конфігуратор і перша нова сутність.

## Why

- Рішення власника 2026-11-15: один рядок мав три смисли, тож його статус не
  можна було прочитати; віха-результат закривається й показує прогрес.
- Статус у документах дублював GitHub і розходився з ним (ROADMAP — «статус»
  без джерела правди).

## Rejected

- Одна віха «Віха 1» для всього — один номер, нічого не читається.
- Віха на частину системи — ніколи не закривається.
- Віха на рядок ROADMAP — П4 змішує API, клієнтські дані й UI.

## Consequences

Нова велика робота в області відкриває нову віху. ROADMAP перелічує віхи з
критеріями й посиланнями, без статусу. Порядок «спершу база, потім екрани»
задає порядок віх, а не окреме правило.
