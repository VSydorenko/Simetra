# ADR-0136: відображенням користувача можна ділитися; код рівня 3 — після перевірки адміністратором

Status: accepted 2026-11-26
Decided by: owner
Spec: [налаштування інтерфейсу](../superpowers/specs/2026-11-26-ui-settings-design.md) §5.9; [модель інтерфейсу](../superpowers/specs/2026-11-26-ui-model-design.md) §6

## Context

Спільне відображення користувача працює з правами того, хто його дивиться. Чуже відображення може показати оманливу кнопку або прочитати те, що бачить лише глядач.

## Decision

- Ділитися відображенням користувача можна за тим самим правом публікувати, що й варіантом списку (ADR-0132).
- Відображення рівня 2 окремої перевірки не потребує.
- Код рівня 3 перед поширенням перевіряє адміністратор.
- Запис із чужого відображення підтверджує платформа власним вікном.

## Why

- Рівень 2 — дані з дозволених компонентів; чужого коду в ньому немає.
- Без прив'язки до скоупу спільне відображення читало б усі скоупи глядача.

## Rejected

- Лише особисте — корисне відображення кожен створював би сам.
- Поширення коду без перевірки — чужий код з правами глядача.

## Consequences

Рішення архітекторки: читання прив'язане до скоупу відображення; перевірка прив'язана до хешу тіла — зміна тіла знімає перевірку й поширення. Потрібен екран перевірки й позначка автора на відображенні. Поширення між скоупами не передбачено.
