# ADR-0002: Формат — JSON-метадані, TS-модулі й SQL; компілятор — єдині двері для всіх поверхонь

Status: accepted 2026-09-24
Decided by: owner
Spec: [платформна спека](../superpowers/specs/2026-09-24-simetra-platform-design.md) §2 (Р2, Р3), §5; [спека П2](../superpowers/specs/2026-09-28-p2-metamodel-compiler-design.md) §2 (М12), §8

## Context

Метадані редагують люди, агенти й конфігуратор, а поведінка (хуки, запити
рухів) лишається кодом. Якщо кожна поверхня (CLI, Vite, MCP, студія) читатиме
метадані по-своєму, система матиме кілька правд і її можна буде обійти.

## Decision

- Конфігурація — це JSON-метадані, TS-модулі поведінки й SQL-файли модулів;
  типи генеруються кодогеном (Р2).
- Компілятор конфігурації — єдині двері для CLI, Vite-плагіна, MCP і
  конфігуратора (Р3): завантаження або приймає конфігурацію, або падає з
  діагностикою.
- Поверхні — тонкі обгортки над тим самим API компілятора з тими самими
  Zod-входами, у порядку API → CLI → MCP → Vite-плагін → студія (М12).
- Двері в репо тримає `simetra compile --all`: у pre-commit — з `--staged`
  (`pnpm metadata:check`) і в CI (М12).

## Why

- Систему неможливо обійти: одна реалізація стадій 1–5 у T1 і одна реалізація
  рендера й плану в T2; поверхні їх лише викликають
  ([платформна спека](../superpowers/specs/2026-09-24-simetra-platform-design.md) §3.1, §5).
- Агент — повноцінний користувач конфігурації, а обгортка над готовим API
  коштує мало (М12), тож агентська поверхня доступна з першого дня.
- Метадані редагує інструмент, тому формат мусить бути diff/merge-дружнім JSON;
  поведінка в TS не вимагає DSL, який ніколи не покриє реальні правила.

## Rejected

- Vite-плагін і MCP у П2 одразу — Vite потребує host, студії потрібен
  конфігуратор; двері з'являються разом із ними (М12).
- Поверхня зі своїм читанням метаданих — створює другу правду й дозволяє
  обійти діагностику.

## Consequences

Легше: будь-яка нова поверхня — це обгортка, а не нова логіка. Важче: кожна
правка метамоделі проходить через компілятор і його діагностику. Не «виправляти»:
гачок `init` не ставить pre-commit сам — двері вмикає людина свідомо.
