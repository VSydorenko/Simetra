# ADR-0010: Межа з фреймворками — T5 імпортує лише React, контракти T4 і адаптер навігації

Status: accepted 2026-09-24
Decided by: owner
Spec: [платформна спека](../superpowers/specs/2026-09-24-simetra-platform-design.md) §2 (Р16), §3.1

## Context

Платформа мусить пережити заміну host-фреймворку чи бібліотеки рушія даних без
переписування UI. Якщо компоненти T5 імпортують роутер, host чи бібліотеку
даних напряму, кожна така заміна зачепить увесь UI.

## Decision

- T5 імпортує лише React, контракти T4 і інтерфейс адаптера навігації (Р16).
- Типовий адаптер навігації на TanStack Router живе в T6. TanStack Start —
  лише в шаблоні host і в студії.
- Бібліотеки рушія даних стоять за адаптерами, а згенерований код звертається
  до контрактів Simetra, а не до API бібліотек.
- Правило — лінт-зона ярусів із негативним тестом.

## Why

- Заміна host чи бібліотеки зводиться до іншого адаптера, а не до переписування
  UI (Р16).
- Правило не залежить від дисципліни: його тримає лінт-зона, а негативний тест
  доводить, що вона справді спрацьовує
  ([платформна спека](../superpowers/specs/2026-09-24-simetra-platform-design.md) §3.1).

## Rejected

- Прямий імпорт роутера чи рушія даних у T5 — звʼязує UI з конкретним
  фреймворком.
- Межа «за домовленістю» без лінту — розмивається першим же зручним імпортом.

## Consequences

Легше: заміна адаптера локальна. Важче: кожна нова залежність T5 мусить пройти
через контракт. Не «виправляти»: зона діє й на студію designer окремо — лише
`src/studio` імпортує TanStack Start. Рушій колекцій після ADR-0079 — власне
ядро T4, але публічний контракт фасаду T4 не змінився.
