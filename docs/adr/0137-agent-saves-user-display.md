# ADR-0137: агент зберігає відображення користувача сам

Status: accepted 2026-11-26
Decided by: owner
Spec: [налаштування інтерфейсу](../superpowers/specs/2026-11-26-ui-settings-design.md) §5.9 «Поширення й агент»

## Context

Агент допомагає користувачу написати відображення. Треба вирішити, чи діє воно одразу, чи лише після перегляду людиною.

## Decision

- Відображення користувача, яке створив агент, зберігається й діє одразу, без проміжної чернетки.

## Why

- Власник обрав швидкість для користувача.
- Особисте відображення бачить лише автор; ризик поширення закриває ADR-0136.

## Rejected

- Агент пише лише чернетку, що діє після перегляду людиною (рекомендація архітекторки: захист від підкинутих інструкцій у даних, які читає агент) — повільніше для користувача.

## Consequences

Запобіжники архітекторки, які власник ще не підтвердив: відображення несе позначку «автор: агент» та ідентифікатор клієнта агента (`act.sub`), який сервер бере з claims запиту; поширення — окрема дія людини з правом публікувати, агент не поширює. Відображення агента може читати все, що читає користувач, і викликати оголошені команди інтерфейсу; ці виклики йдуть без `act`, тож стеля агента на них не діє. Спільних налаштувань інтерфейсу запит агента не пише (спека налаштувань інтерфейсу §5.7). Чи підтверджує платформа першу дію запису з такого відображення — не вирішено, спека §5.9.
