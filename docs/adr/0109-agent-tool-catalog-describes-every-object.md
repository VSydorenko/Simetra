# ADR-0109: каталог інструментів агента — у T3, загальні дієслова над метаданими; `describe` перелічує всі об'єкти; MCP і designer — адаптери

Status: accepted 2026-11-24
Supersedes: ADR-0107
Decided by: architect
Spec: [П4-F](../superpowers/specs/2026-11-24-p4-f-agents-design.md) §5.3

## Context

Інструменти `data-read` і `data-command` designer уже кличуть T3 (`runCommand`, серверне читання) під claims з `act`, але лише на базі розробника (ADR-0069), і designer не їде в продакшн (ADR-0030). Вхід агента в продакшні потребує тих самих дій. Розмір `tools/list` обмежений: клієнти обрізають довгі переліки, а designer тримає гейт бюджету описів. ADR-0107 обмежував опис метаданих об'єктами, які користувач може читати; фільтр потребував третього дзеркала предиката читання поряд із SQL і клієнтським (`packages/simetra/src/data/store/rights.ts`), а повний клієнтський каталог (`packages/create-simetra-app/template/generated/client-catalog.json`) і так їде в браузер кожному користувачу без фільтра.

## Decision

- Каталог інструментів агента живе в T3 над `CommandRuntime`; MCP-вхід застосунку й `data-read`/`data-command` designer — адаптери цього каталогу.
- Каталог — кілька загальних інструментів: опис метаданих (усі об'єкти каталогу рантайму, без передбачення прав), читання (картка, сторінка, кількість), запис (створення, зміна) і видалення (позначка видалення, видалення). Операції — операції рантайму, дозволені виду об'єкта. Запис і видалення — різні інструменти, бо позначки MCP належать інструменту, а не виклику. Інструменту на кожен об'єкт немає.
- Межу прав тримають RLS і ядро команд на читанні й записі: відмова — код каталогу з наступним кроком для агента.
- Мітки метаданих дають описи й назви полів; вид дії дає позначки MCP.

## Why

- Один механізм читання й запису агента для продакшну й бази розробника; нового шляху в базу немає (платформна спека Р21).
- Розмір `tools/list` не росте з кількістю об'єктів застосунку.
- Фільтр опису за правами не дає конфіденційності: метадані не захищаються правами (ADR-0110), а структуру клієнтський каталог уже віддає браузеру. Третє дзеркало предиката читання суперечило б ADR-0102.

## Rejected

- Окремий MCP-сервер host-а, каталог у designer, інструмент на об'єкт — з причин ADR-0107.
- Опис лише читабельних об'єктів (ADR-0107) — третє дзеркало предиката читання без виграшу конфіденційності.

## Consequences

Адаптери нічого не обчислюють самі. Нова операція рантайму (наприклад, проведення документа, П4-C) з'являється в наявному інструменті з операцій рантайму, а не новим інструментом на об'єкт. Агент може описати об'єкт, який користувач не читає; читання чи запис тоді відмовляє кодом каталогу. Фільтр опису за правами не додавати як «зміцнення безпеки».
