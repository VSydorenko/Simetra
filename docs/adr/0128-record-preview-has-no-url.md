# ADR-0128: попередній перегляд запису не має власної адреси; посилання веде на повну сторінку

Status: accepted 2026-11-26
Decided by: owner
Spec: [модель інтерфейсу](../superpowers/specs/2026-11-26-ui-model-design.md) §5.6 «Попередній перегляд запису», «Режим відкриття»

## Context

Запис відкривається трьома способами: бічна панель, вікно, сторінка. Треба вирішити, що з цього має адресу.

## Decision

- Попередній перегляд запису (панель, вікно) — тимчасовий стан рамки; адреси не має.
- «Копіювати посилання» з перегляду дає адресу повної сторінки запису.
- Стек переглядів не зберігається.
- Типовий режим відкриття береться з виду, потім з об'єкта; користувач перемикає його для типу об'єкта.

## Why

- Адреса — це обіцянка відтворити екран; перегляд над списком залежить від стану списку, якого в отримувача немає.
- Маршрути з одного рядка лишаються двома: список і картка.

## Rejected

- Перегляд як параметр пошуку в адресі — посилання відкривало б список у чужому стані.

## Consequences

Назад у браузері закриває не перегляд, а сторінку; вихід із перегляду з незбереженою чернеткою питає сторож виходу (ADR-0138).
