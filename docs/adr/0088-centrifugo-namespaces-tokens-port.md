# ADR-0088: Centrifugo — три простори з recovery; токени Ed25519 через JWKS host-а; вузький порт; без примусового відписування

Status: accepted 2026-11-08
Decided by: architect
Spec: [профіль `postgres`](../superpowers/specs/2026-11-08-postgres-profile-design.md) §5.3, §6, §7 (ПГ7–ПГ10)

## Context

Транспорт сигналу (ADR-0083) потребує конфігурації сервера сигналів, моделі
токенів і порту, через який host їх видає. Відкликане право має перестати
тримати підписку, але другий шлях з бази до сервера сигналів ускладнив би
систему.

## Decision

- Споживач outbox — логін `simetra_signals` з `SELECT` і `DELETE` лише на
  outbox через групову роль `simetra_signal_consumer`; обидва DSN споживача —
  пряме з'єднання або пулер у сесійному режимі, transaction-режим заборонено
  (ПГ7).
- Простори `simetra`, `simetra-rights`, `simetra-user` з історією й
  `force_recovery`; клієнт не публікує, не читає історію й не підписується
  без токена (ПГ8).
- Токени — EdDSA (Ed25519), ключі через JWKS host-а, з `kid` і правилом
  перекриття під час ротації; TTL токена каналу 5 хв, з'єднання — 15 хв (ПГ9).
- Порт сервера сигналів вузький — лише видача токенів (з'єднання, канал) і
  JWKS; публікації йдуть через outbox, присутності немає (ПГ10).
- Серверного примусового відписування немає: на відкликання права сервер не
  кличе `unsubscribe` чи `disconnect`. Рівно один інстанс Centrifugo на
  застосунок (рушій історії — пам'ять інстансу).

## Why

- Споживач тримає `LISTEN` і advisory lock транзакції; найменші права
  обмежують шкоду від витоку DSN (ПГ7).
- JWKS дає ротацію без перезапуску Centrifugo; короткий TTL обмежує час, коли
  відкликане право ще тримає підписку (ПГ9).
- Ширший контракт (публікація з сервера, присутність) не має споживача; кожен
  метод порту — поверхня для другого адаптера (ПГ10).
- Без відписування клієнт тримає підписку щонайдовше TTL (5 хв), бачачи лише
  id і версії, а перечитування під RLS їх відсіює; той самий клас залишку
  вже прийнято для обсягів `own`; відписування на кожну зміну прав рвало б
  з'єднання й давало б зайве перечитування (§6.2 профілю).
- Recovery скорочує перечитування після короткого розриву; коректність від
  нього не залежить (ПГ8, ADR-0083).

## Rejected

- Transaction-режим пулера для споживача — ламає `LISTEN` і advisory lock.
- Підпис токена симетричним секретом — немає ротації без перезапуску.
- Широкий порт (публікація, присутність) — немає споживача.
- Примусове відписування при відкликанні права — другий шлях з бази, зайві розриви.
- Кілька інстансів Centrifugo без спільного рушія — стан історії в пам'яті інстансу.

## Consequences

Якщо страховка знадобиться, шлях уже є: outbox прийме метод `disconnect`
(`CHECK (method = 'publish')` розширюється), окремим рішенням. Redis-рушій
для кількох інстансів — поза першою віхою. Не «виправляти»: відсутність
`unsubscribe` на відкликанні — рішення, а не пропуск.
