# ADR-0116: тип `RichText` — у віці «Мультимовні дані»

Status: accepted 2026-11-25
Decided by: owner
Spec: [мультимовні дані](../superpowers/specs/2026-11-24-multilingual-data-design.md) §5.7

## Context

Платформна специфікація ставила тип `RichText` у модуль «Документація» після першого релізу (таблиця відкладеного). Дослідження клієнтських даних уже ухвалило його форму: ProseMirror JSON у `jsonb`, редактор Tiptap лише з MIT-розширеннями, перевірка за профілем — відмова, а не відсікання. Опис запису в бізнес-застосунку зазвичай одночасно мультимовний і форматований.

## Decision

Тип `RichText` будується у віці «Мультимовні дані» (блок B7 специфікації) і може бути `localized`; модуль «Документація» потім бере готовий тип.

## Why

- Мультимовний опис без `RichText` довелося б тимчасово тримати як `Text` і потім мігрувати.
- Форма типу вже вирішена, тож перенесення віхи не відкриває нових розвилок.

## Rejected

- `RichText` після першого релізу, разом із модулем «Документація» — описи тимчасово `Text`, міграція типу пізніше.

## Consequences

- Платформна специфікація (таблиця відкладеного) оновлюється задачею 0 плану B7.
