# ADR-0070: Створення тенанта — команда create кореня скоупу плюс членство й rootCreator однією транзакцією

Status: accepted 2026-10-27
Decided by: owner
Spec: [спека П4](../superpowers/specs/2026-10-26-p4-runtime-design.md) §5 (Рт16), §6.13; [спека прав](../superpowers/specs/2026-10-17-rights-design.md) §2 (Рх7, Рх9, Рх19)

## Context

Перша міграція першого споживача створює корінь скоупу й членство як довідники Simetra. Після неї застосунок не пише таблиць виду напряму, тож без команди нові тенанти не з'являються. Права (ADR-0053) мали виняток для `create` кореня скоупу, але не описували самої операції.

## Decision

- Створення тенанта входить у П4-A: згенерована команда `create` кореня скоупу в одній транзакції вставляє корінь, рядок членства творця й призначення ролі `rootCreator` через названий привілейований шлях платформи (Рт16).
- Це змінює й доповнює Рх7, Рх9, Рх19: `create` кореня — єдиний виняток, його дає лише роль рівня `global` чи `everyUser` явним грантом, а `rootCreator` призначається творцю в тій самій транзакції.

## Why

- `CustomTable` як тимчасова форма означала б другу переробку (Рт16).
- Без команди після першої міграції нові тенанти не з'являлися б.

## Rejected

- `CustomTable` як тимчасова форма створення тенанта — друга переробка (Рт16).

## Consequences

Привілейований шлях створення кореня — названий, а не загальний: інших привілейованих шляхів повз права користувача команди не мають без окремого рішення (спека прав §8). Виняток із запобіжника ⊆ для `rootCreator` обмежений рівно новим скоупом (ADR-0056).
