# ADR-0071: Хуки = події запису 1С (beforeWrite, onWrite); один контекст; без зовнішнього I/O; прапорця «пропустити хуки» немає

Status: accepted 2026-10-30
Decided by: owner
Spec: [спека П4](../superpowers/specs/2026-10-26-p4-runtime-design.md) §5 (Рт20, Рт21), §6.9

## Context

Модуль об'єкта потребує хуків запису. Розробник 1С має впізнавати модель, а імпорт конфігурації 1С має переноситися механічно. Транзакція команди повторюється при `40001` і `40P01`, тож хук може виконатися двічі.

## Decision

- Ключі модуля об'єкта — англійські назви подій запису 1С у camelCase, той самий словник, що й події `EventSubscription`: `beforeWrite` (`ПередЗаписью`) і `onWrite` (`ПриЗаписи`) на операціях `create`, `update`, `markDeletion`. Яку подію викликає операція — факт `OPERATION_EVENTS` T0, а не гілка за назвою виду. `delete` подій не викликає (Рт20).
- Хук отримує один об'єкт-аргумент: нові поля додаються без зламу контракту. `ctx.action` — операція фази, `ctx.isNew` — ознака `create`, `ctx.additionalProperties` — дані хуків однієї фази (Рт21).
- Хук не робить зовнішнього I/O; зовнішня дія — лише `ctx.afterCommit` (Рт21).
- Прапорця «пропустити хуки» немає: імпорт і мігратор пишуть повз `runCommand` з `simetra.write_mode = 'import'` (ADR-0026), інваріанти бази діють завжди (Рт21).

## Why

- Розробник 1С упізнає модель; імпорт конфігурації 1С переносить подію обробника й `<Event>` підписки механічно; один словник подій для SQL-підписок і TS-хуків (Рт20).
- Без правила про зовнішнє I/O повтор `40001` чи `40P01` двічі виконав би зовнішню дію (Рт21).
- Прапорець обходу в команді дав би будь-якому викликачу шлях повз поведінку застосунку (Рт21).

## Rejected

- Власний словник подій — втрачає відповідність 1С (Рт20).
- Прапорець skip-hooks в операції — шлях повз поведінку застосунку (Рт21).

## Consequences

Події видалення прийдуть разом із видаленням позначених. Хуки без побічних дій дозволяють перевірку без запису тією самою командою з `ROLLBACK`. Хуки власних команд модуля — окремі ключі (`commands.<дія>.{ before, after }`), не події запису. «Пропуск хуків» не слід додавати для зручності імпорту.
